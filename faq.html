常见问题

你有问题,她有答案。点开看看,不行再去 GitHub 提 issue~

dsh-mini 是什么?
dsh-mini 是 DeepSeek Harness 的DeepSeek Harness Mini:把完整的 AI 助手打包成单个 exe 安装包,双击安装完就能用。开源、免费、MIT 协议。
安装需要管理员权限吗?
不需要。它默认装在你自己的用户目录下(%localappdata%\DeepSeekHarnessMini),公司电脑、学校电脑也能装。
需要先装 Node.js 或配置环境吗?
不用。安装包自带 Node 24 运行时,环境全封装好了,装完即用,不污染系统。
怎么升级到新版本?
直接下载新版本安装包,覆盖安装即可。你的会话、设置、记忆数据全部原样保留,不会丢。
注意:v0.1.1 起内核升级到 dsh 0.1.5,面板改用访问令牌,旧的 127.0.0.1:2233 书签会提示 401,删掉重开一次(托盘会自动带你进去,见下一条)即可。
面板打不开、提示 401 或要我输密钥?
这是 dsh 0.1.5 起的访问令牌机制:内核每次启动会生成一枚随机令牌,只有带令牌的地址才能进面板,裸开 http://127.0.0.1:2233 一律 401。
你不需要做任何事——托盘会自动抓着令牌把面板打开;进过一次后浏览器记住 30 天,同一地址之后免输。
需要发给手机或远程电脑时:右击托盘鲸鱼娘 →「复制面板地址(含 token)」,把整条地址发过去即可。
旧书签提示 401 是正常的,删掉重开或用托盘打开就行。
怎么卸载?
从「开始菜单 → 设置 → 应用」里找到 dsh-mini 卸载,或运行安装目录里的卸载程序。卸载向导全程中文,她会哭哭挽留你(数据会清掉,想留先备份)。卸载后可能残留 1~4 个几十 KB 的小文件,无害,重装即覆盖。
我的数据存在哪里?
在安装目录的 home 文件夹里(会话、设置、记忆都在)。升级不受影响,卸载会一起清掉。
端口被占了怎么办?
托盘程序支持端口参数:运行 DshMini.exe 2255 用 2255 端口启动;DshMini.exe --stop 停止服务。默认端口冲突时换个端口即可。
收费吗?能商用吗?
完全免费,MIT 协议开源,商用、改版、二次开发都欢迎。源码在 GitHub。
GitHub 下载慢怎么办?
用 Gitee 国内镜像下载(gitee.com/wyr233/dsh-mini/releases),速度更快。两个渠道内容一致。
